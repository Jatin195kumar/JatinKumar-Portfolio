# Jatin Kumar — Personal Portfolio

A responsive personal portfolio built with **HTML, CSS, and vanilla JavaScript**. It uses a light, minimal visual style and a JK initials mark instead of a profile photo.

## Files

- `index.html` — page structure and portfolio content
- `style.css` — responsive styling, layout, and animations
- `script.js` — mobile navigation, current year, and scroll reveal

## Run locally

No build tools or dependencies are required.

1. Extract the ZIP file.
2. Open `index.html` in a browser.

For a local development server, you can use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Sign in to GitHub and create a repository named `Jatin195kumar.github.io` (or use another repository name).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. If you use a repository other than `Jatin195kumar.github.io`, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for the deployment to finish. GitHub will show the published URL in Settings → Pages.

## Personalize before publishing

Search `index.html` for these items and update them:

- LinkedIn: replace the placeholder `href="#"` with your actual LinkedIn profile URL.
- Project links: each project currently links to `https://github.com/Jatin195kumar` because exact repository URLs were not supplied. Replace each with its own repository URL when available.
- Education: add study dates, expected graduation year, and CGPA if you want them shown.
- Add real internship, certification, and achievement details only when you have verified information to include.

The contact email and GitHub profile are set to the details supplied in the conversation.
